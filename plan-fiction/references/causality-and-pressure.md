# 因果与压力

用于诊断情节断裂、角色被动、冲突重复与篇幅失控，按需读取，不把检查表格直接抛给用户填写。

## 同时检查内外两层因果

构思情节时，外层因果回答**“前一个事件如何导致后一个事件”**，内层因果回答**“这个人物为什么因此作出下一步选择”**。外部事件排列合理，不等于人物的反应和决定已经成立。

将关键节点连成简明的因果链：

> **人物带着某种期待采取行动 → 遭遇预料之外的结果 → 按自身知识边界与旧执念解读结果 → 作出下一步选择 → 形成新的处境。**

这条链路用于检验节点之间是否断档，不要求每个场景都拆成五段，也不强制时间顺叙。安静的拒绝、迟迟未发出的消息、假装不知情的继续等待，只要改变了后续关系或局势，同样是有后果的行动。

当大纲出现“然后他去了……接着又遇到……”的流水账时，挑出连接处追问：**“上一幕的什么结果，迫使他决定走这一步？”** 若答案只是“因为后面需要他到场”，就修改前一幕的后果或人物动机。巧合可以用来开局或制造麻烦，但不能长期推着被动的角色走，更不能在结尾替他解开核心困境。

## 用场景卡核验关键转折

助手在内部梳理关键转折时，可用以下七项核验（普通推进节点压成一句话即可，不为简单故事堆砌大表格）：

| 核验项 | 需要回答的具体内容 |
| --- | --- |
| 进入此场的动因 | 前面的哪项决定或局势变化把人物推到了这里 |
| 此刻的期待 | 他这一趟准备争取什么，原以为怎样做就能奏效 |
| 实际发生的事 | 现场的具体行动、对方反应或新显露的事实 |
| 内在解读 | 他如何理解眼前的变化，原有的认定受到什么冲击 |
| 选择与代价 | 他最终选了什么，为此放弃或冒险赌上了什么 |
| 局势变化 | 这一幕结束时，关系、认知、处境或筹码改变了什么 |
| 后续牵引 | 这个结果使哪一个后续节点变得不可避免 |

下一幕应当在具体处境中检验上一幕的决定（例如人物刚刚决定不再替某人兜底，下一幕就出现一个看似只需顺手帮一把的请求），但不要脱离主线安排毫无关联的考验。

## 让压力来自具体两难与代价

避免用两句抽象口号代替冲突。从人物已有的关系和处境中，挑出真正让他左右为难的拉扯：

- 他死守的自我解释，与越来越难忽视的眼前事实。
- 他真正想要的生活，与重要他人期待他扮演的角色。
- 眼下能稳妥保住的利益，与他长期看重的自我认同或承诺。
- 他赖以自保的惯用手段，与办成这件事必须迈出的那一步。
- 对手的阻拦，与对手同时具备的合理诉求、善意或苦衷。

把冲突收束到一个**当下的具体选择**：选哪一边，就会立刻失去哪样具体东西。如果场面里存在显而易见、毫无代价的第三条路，先在构思中堵住这条退路，不靠让角色突然降智来维持冲突。

阻力可以来自具体的人、行业规矩、空间环境或人情契约。把抽象的“时代压力 / 社会偏见”落到具体是谁有权拒绝什么、哪条规矩会带来什么实际损失。对手同样有自己的目标与信息盲区。

## 情节停滞时的升级选项库

当故事在中途显得平淡、角色被动或困难原地打转时，从下表中挑出最贴合当前人物的 2–3 个方向转化为具体候选（切勿机械套用全部选项）：

| 当前停滞信号 | 可尝试的破局方向 | 需核对的成立条件 |
| --- | --- | --- |
| 主角一直观望、不肯表态 | 为“开口”和“继续沉默”分别设定立刻兑现的不同代价 | 代价必须长在已有关系里，不是作者强行逼他坦白 |
| 隐瞒秘密缺乏戏剧张力 | 让读者或配角先察觉破绽，看主角如何圆谎与招架 | 不必把所有底牌都瞒到连读者也看不懂人物在干什么 |
| 解决问题过于顺手 | 让真正奏效的补救手段同时伤及他在乎的另一件事 | 副作用直接源自补救动作本身，而非天降横祸 |
| 目标达成后却觉得平淡 | 检验到手的结果是否真的填补了他的内在所求 | 允许“得到了却发现滋味变了”，不强求反转成“其实不想要” |
| 困难只是同质化重复 | 让前一次的小妥协演变成后一次更难撤回的绑定或亏空 | 每一次选择都比上一次多押上一点具体筹码 |
| 出现轻易脱困的捷径 | 给捷径标上身份、尊严或关键关系的暗码标价 | 诱惑与代价合乎人情，不靠无端恶意强行下毒 |
| 人物形象过于无瑕被动 | 让自保、好胜、体面或逃避心理影响他的一次关键判断 | 只在故事人物身上找弱点，不影射或追问用户个人经历 |
| 危机遥远、随时能拖延 | 明确拖延会先毁掉哪件具体小事，或引入合理的节点期限 | 期限必须来自事件自身规律，不硬贴虚假倒计时 |
| 对手只会使坏、毫无悬念 | 给对手补上合理的自身利益，或在一件事上与主角目标重合 | 增强对手的立体感，不等于强行洗白或强行和解 |
| 诺言或谎言只像口头装饰 | 让这句诺言或谎言直接限制他下一步能选的办法 | 哪怕最后未被拆穿，也必须改变双方的相处分寸 |
| 总靠外力或巧合帮主角解围 | 撤掉救兵，迫使主角用现有条件自己选一条有损的路 | 考验的是人物取舍，不等于伤亡越重、场面越惨越好 |

压力的轻重以**对这个具体人物的分量**来衡量。对一个习惯讨好长辈的人来说，当面撤回一句承诺的难度，可能远胜于经历一场外部惊险。始终尊重用户想要的题材基调与冷暖分寸。

## 留出呼吸与消化的节奏

持续不断的高压会让读者麻木。在关键冲击或付出代价之后，允许留出短暂的平稳、误以为过关的喘息、沉默或收拾残局的时刻。

这些缓和段落不是水字数的过场，它们承担着**看清损失、重新揣摩对方意图、消化认知落差并酝酿下一个决定**的作用。哪怕外部动作放缓，人物的内在判断或读者的期待也应在这里发生推进。

## 适配中短篇的容量边界

若用户已指定字数，按指定字数控制规模；未指定时，待核心事件与主要人物初现后确认一次篇幅倾向：

- **短篇规模**：聚焦一次核心处境、一组主导矛盾与少数几次有分量的选择，通常以 **4–8 个关键因果节点**为起点（单场景或横截面短篇可更少）。默认不另开支线，往事尽量融进当下的动作与反应中。
- **中篇规模**：可容纳多轮行动与反制、关系阶段性演变及 1–2 条实质影响主线的辅助线，通常以 **8–16 个关键节点**为起点。节点代表因果转折，不等同于固定章数或均分字数。
- **超载时的压缩办法**：当构思超出目标篇幅时，优先**合并功能重叠的配角、让同一个场景同时完成两项叙事任务、缩短与核心问题无关的时间跨度**；不要保留全部十几幕却把每一幕都写得像梗概一样仓促。
- **填补“假过渡”**：大纲里凡是只写一句“经过一番相处，他渐渐改变了看法”的地方，往往缺了一整段迫使他改变的具体事件；要么补上那次关键触动并从别处腾出篇幅，要么调整结局。

**节点增删检验**：试着遮住某个节点，看后续的人物选择、关系走向与读者理解是否完全不受影响？如果毫无影响，就将其删除或并入相邻场景；如果拿掉它会导致后续态度失去依据，哪怕这一幕看似安静，也必须保留。
